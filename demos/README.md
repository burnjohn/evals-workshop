# Demos

The four changes from the talk and one control, one folder each. Every folder has the prompt from the slide (the same text as its Copy button), the state to start from, the command that checks the result, and one variation to try yourself.

| Demo | Part of the harness | On stage |
|---|---|---|
| `01-release` | `make-release` + `semver-rules` skills | live |
| `02-review` | `code-review` skill | live, one case; the full matrix is recorded |
| `03-implementer` | `implementer` agent + `db-rules` skill | prepared diff and recorded run |
| `04-workflow` | `run-plan` skill | prepared diff and recorded traces, one per case |
| `05-no-skill` | `code-review`, with the skill instructions removed | the question and the setup; run it yourself |
