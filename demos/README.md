# Demos

The 4 changes from the talk and 1 control, 1 folder each. Every folder has the prompt from the slide (the same text as its Copy button), the state to start from, the command that checks the result, and 1 variation to try yourself.

| Demo | Part of the harness | On stage |
|---|---|---|
| `01-release` | `make-release` + `semver-rules` skills | live: add a regression case, then break the skill |
| `02-review` | `code-review` skill | live: write a candidate, run the matrix. The 11/11 vs 6/11 table is a recorded run |
| `03-implementer` | `implementer` agent + `ui-rules` skill | live: write the eval from scratch, then fix `ui-rules` |
| `04-workflow` | `run-plan` skill | live: the docs-only rule, then break it |
| `05-no-skill` | `code-review`, with the skill instructions removed | the question and the setup; run it yourself |
