# Checklist for your own harness

1. Read 20 real runs of one skill.
2. Write three things that must always be true.
3. Check the result (files, git, JSON), not the wording.
4. Add a control: a case where the right answer is nothing.
5. Break the prompt on purpose and watch the check go red.
6. Run it more than once before you believe it.
7. Make one check required. "Not run" is not green.
8. Only then add a judge, and compare it with a person first.
